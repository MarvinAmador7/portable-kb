# Does inspecting the evidence help you decide?

This is a small owner exercise, not a completed benchmark. No owner decision,
inspection time or usefulness result has been measured. A person who has already
read both views can give product feedback, but cannot supply a clean first-exposure
comparison.

## First-use check

Use one view, selected before reading: [concise cited answer](ordinary-answer.md)
or [claim-by-claim evidence view](answer.md). Both are honestly hand-authored from
the same [fictional Mosaic packet](source-manifest.json); neither is a measured
skill output. Answer content is intended to be comparable, while detail, wording,
length and citation presentation differ. Any observed difference therefore tests
the whole presentation, not the skill or evidence format alone.

Scenario: You own Mosaic Studio. Staff want to repeat the board summary to the
client: USD80/hour is the standard rate, Lumen's redesign creates 85% margin, and
November 20 launch is guaranteed. It is fictional November 6. Use the selected
answer and open any source links you need. Start timing when the answer opens;
stop when you have written your decision. Do not include setup time.

Record these without viewing the facilitator note below:

1. What rates would you authorize the team to describe, and for which work?
2. What October figure would you report, and what would you avoid claiming caused it?
3. What would you tell the client about launch, and what specific evidence or decision
   would you need next? Are any unrelated tasks affected?
4. Which supplied record or calculation changed your decision, if any? Which
   claims could you verify, and which did you leave unresolved?

Then record elapsed seconds, source links opened, any failed links, clarification
questions you needed to ask, and confidence in each decision with a short reason.
Confidence is a self-report, not correctness. Ask whether the view saved effort,
added useful inspection or was extra reading; capture the person's own words.

```text
Participant identifier (consented, non-sensitive):
Previous exposure to this case:
Assigned view and assignment method:
Started / finished / elapsed seconds:
Decisions and reasons:
Sources inspected / failed links:
Clarifications requested:
Confidence per decision and basis:
What helped / what was extra work:
```

Keep personal/company data out of public results without authorization. Record
actual behavior; do not infer inspection counts or elapsed time from an agent trace.

## Small comparison

Give different people one randomly assigned view each; use the same packet and
questions. If only one owner is available, compare different matched cases in a
counterbalanced order and report the case/order confound. Do not show both views
of this same case and call the second attempt an independent trial. Capture
prior exposure and familiarity. No minimum sample establishes a statistical win;
this is an early usability probe.

Have a reviewer, with presentation labels removed from the decision responses,
inspect the actual decisions and cited passages. Report correct supported
decisions, consequential unsupported assertions, unnecessary withheld decisions,
legitimate open questions, elapsed time and inspection burden separately. Avoid
a single winner score or interpreting added length as added reliability. The
reviewer should use the case evidence, not the person's confidence rating.
