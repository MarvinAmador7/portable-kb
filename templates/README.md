# Authoring templates

These files are design-time starters, not valid knowledge instances. Replace
every `REPLACE_*` marker, remove comments that are not useful, add/omit optional
fields according to `docs/schema.md`, and keep new work `draft` until its review
gates are satisfied.

Templates live outside the future `knowledge/` bundle because OKF treats every
non-reserved Markdown file inside a bundle as a concept.
